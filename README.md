# Expense Tracker / Budget Manager

## Pages & Features

### 1. Dashboard
- Monthly spending vs. budget gauge chart
- Spending breakdown by category (donut chart)
- Recent transactions feed
- Savings goal progress bars

### 2. Transactions
- Add income / expense entries
- Transaction list with search, date range, category filters
- Recurring transaction setup (rent, subscriptions)
- Bulk import from CSV / bank statement
- Attach receipt images

### 3. Budgets
- Set monthly budgets per category
- Budget vs. actual comparison bars
- Over-budget alerts & notifications
- Rollover unused budget option

### 4. Categories
- Default categories (food, transport, utilities, etc.)
- Create custom categories with icons & colors
- Category spending trends over time
- Subcategory support

### 5. Savings Goals
- Create savings goals with target amount & date
- Track progress with visual indicators
- Allocate contributions from income
- Goal completion celebration

### 6. Accounts
- Manage multiple accounts (checking, savings, cash, credit card)
- Account balance overview
- Transfer between accounts
- Account reconciliation

### 7. Reports
- Monthly / yearly spending summary
- Income vs. expenses trend chart
- Category comparison month-over-month
- Net worth tracker
- Export as PDF / CSV

### 8. Settings
- Currency & locale preferences
- Notification preferences (daily summary, over-budget)
- Data export / import
- Account & profile management
